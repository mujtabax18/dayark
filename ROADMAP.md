# DayArk roadmap

This is an **ideas list**, not a release schedule. Features may change as the project grows. I built DayArk for daily use; contributors are welcome to suggest a better direction.

## Present in the source today

- Local-first personal data storage; diary, habits, reminders, expenses, invoices and other daily records
- Life Archives with people, relationship charts, memories/photo albums and life events
- Local sync, QR pairing and TLS certificate pinning
- Encrypted portable backups and legacy restore compatibility
- Media library, document scanning, existing PDF/video/audio-related tools
- System-aware appearance, light/dark mode and five theme presets

Presence in the source does not guarantee full testing on every supported platform. The [readiness report](OPEN_SOURCE_READINESS.md) tracks open validation work.

## Near-term improvements I'd love help with

- Consistent, attractive, accessible UI for mobile and desktop
- More flexible **multiple themes** and deeper personalization (building on existing presets)
- Better app startup speed, database query efficiency, responsiveness and lower memory use
- More automated tests and reliable cross-platform releases
- Documentation, installation instructions and open-source contributor onboarding
- Improved memory albums, relationships, search and Life Archive usability
- Additional backup safety, local sync resilience and clearer conflict resolution

## Ideas for future modules

- **Local AI assistant / chatbot**, with on-device models where practical and clear privacy controls
- **LAN chat with file sharing**, without relying on an external chat account
- **Local-network voice calling** between compatible devices
- **Password manager**, with independently reviewed security design (do not rush this feature)
- **Simple, fast notes** with labels, pinning and search—a Google Keep-like experience
- Improved **to-do lists, alarms and reminders**
- Better PDF reader/editor and document organizer
- Better audio and video player experience; local radio options
- More helpful personal-life tools suggested by users

An item on this list is not an implemented feature, an announced delivery date, or a guarantee that every platform will support it. For privacy- or security-sensitive features, design and review should come before coding.

## How to help choose priorities

Open an issue describing your use case, what already works or fails for you, and the simplest improvement that would be useful. If you can contribute a design or implementation, even better.
